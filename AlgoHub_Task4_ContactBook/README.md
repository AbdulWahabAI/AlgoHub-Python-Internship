# AlgoHub Python Programming Internship - Week 4 Project

## Project Overview
This is a command-line interface (CLI) contact book application developed for Week 4 of the AlgoHub Python Programming Internship. It utilizes intermediate Python data structures and algorithms including dictionaries, sets, queues (`collections.deque`), priority queues (`heapq`), and custom sorting techniques.

## Features
* Add new contacts with duplicate checks using dictionaries and sets.
* Sort and display contacts alphabetically.
* Search functionality with automatic recent search tracking via queues.
* Priority contact management using heaps.
* Delete existing contacts easily.
