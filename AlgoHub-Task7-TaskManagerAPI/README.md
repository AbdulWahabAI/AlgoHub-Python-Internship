# AlgoHub Task Management API

Welcome to the **Task Management API** project, developed as part of the **AlgoHub Python Programming Internship Program**. This project showcases the creation of a robust, production-ready, and fully documented RESTful API built with **FastAPI** to efficiently manage daily tasks[span_0](start_span)[span_0](end_span).

---

## 🚀 Project Overview
The Task Management API provides complete **CRUD (Create, Read, Update, Delete)** operations for managing tasks[span_1](start_span)[span_1](end_span). It utilizes **FastAPI** for high-performance request handling and **Pydantic** for strict request/response data validation[span_2](start_span)[span_2](end_span).

---

## 🛠️ Technical Stack & Tools
* **Programming Language:** Python 3.10+
* **Web Framework:** FastAPI[span_3](start_span)[span_3](end_span)
* **ASGI Server:** Uvicorn[span_4](start_span)[span_4](end_span)
* **Data Validation:** Pydantic[span_5](start_span)[span_5](end_span)
* **API Documentation:** Interactive Swagger UI (Auto-generated by FastAPI)[span_6](start_span)[span_6](end_span)
* **Version Control:** Git & GitHub[span_7](start_span)[span_7](end_span)

⚙️ Installation & Setup Guide
​Follow these steps to set up and run the project locally on your machine:
1. Clone the repository:
git clone <YOUR_REPOSITORY_LINK_HERE>
cd AlgoHub_Task7_TaskManagerAPI

2. Set up a virtual environment:
python -m venv venv
# Activate on Windows:
venv\Scripts\activate
# Activate on macOS/Linux:
source venv/bin/activate

3. Install the required dependencies:
pip install -r requirements.txt

4. Run the application using Uvicorn:
uvicorn main:app --reload
